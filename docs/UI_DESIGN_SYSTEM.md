# ProDental UI Design System

Version: 1.0
Status: Foundation Implemented
Owner: Product Design
Last Updated: 2026-08-06

---

## Product Feel

ProDental should feel like a premium enterprise SaaS platform: focused, structured, fast, and predictable.

Reference qualities:

- Linear: clarity and keyboard-friendly density.
- Stripe Dashboard: calm hierarchy and precise surfaces.
- GitHub: familiar navigation and readable operations.
- Vercel: clean whitespace and restrained contrast.
- Notion: approachable information grouping.

## Visual Rules

- Use teal as the default brand color through tokens.
- Avoid hardcoded brand color in new reusable components.
- Use soft borders and light shadows.
- Keep page sections compact.
- Use icons for major headings, metrics, cards, and actions.
- Avoid dashboard clutter and generic CRUD-first presentation.
- Keep the global header calm and platform-owned: one PD logo, one `ProDental` wordmark, one workspace switcher, one global search, and one utility group.
- Move user name, email, and profile links into the user dropdown instead of showing standalone user labels in the header.

## Typography

- Workspace Title: primary page identity.
- Section Title: major workspace regions.
- Card Title: one-purpose card heading.
- Body: operational text.
- Caption: timestamps, helper text, metadata.
- Badge: compact state or category.

## Empty States

Every empty state should explain why it is empty and expose the next relevant action when one exists.

## Verification Workspace V2

Verification Workspace V2 is the visual benchmark for ProDental workspaces.

Rules:

- The queue is the primary product surface.
- Context appears before the queue only to orient the user.
- Timeline, notifications, recent updates, quick actions, pinned notes, and future AI belong in the right awareness column.
- Decorative KPIs, placeholder charts, and oversized empty cards are not allowed.
- Focus Mode remains the edit experience and must not be redesigned by workspace presentation work.
